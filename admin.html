📥 Direct Delivery (optional)

Without this, reviews reach you on WhatsApp and you add them above. To receive them straight to your email instead, deploy the tiny script below once and paste its Web App URL here.

Show the one-time setup (copy & paste)
  1. Go to script.google.com → New project.
  2. Delete the sample code, paste the script below, then click Save.
  3. Click Deploy → New deployment → Web app. Set “Execute as” = Me and “Who has access” = Anyone. Deploy and approve permissions.
  4. Copy the Web App URL and paste it in the box above, then click Save Review URL.
function doPost(e) { try { var d = JSON.parse(e.postData.contents); if (d.type !== 'review') return ContentService.createTextOutput('ok'); var props = PropertiesService.getScriptProperties(); var all = JSON.parse(props.getProperty('reviews') || '[]'); all.unshift({ at: new Date().toISOString(), name: d.name, city: d.city, stars: d.stars, product: d.productName || '', text: d.text }); props.setProperty('reviews', JSON.stringify(all.slice(0, 500))); MailApp.sendEmail(Session.getEffectiveUser().getEmail(), 'New ' + d.stars + '-star review from ' + d.name, d.text + '\n\n' + (d.productName || 'General store review')); return ContentService.createTextOutput('ok'); } catch (err) { return ContentService.createTextOutput('error'); } }

☁️ Publish Catalog to GitHub

Publishing saves the full catalog (products, categories, images + wholesale list) to your repo — every visitor sees it within ~1 minute.

🔑 GitHub Token Setup (one time)

Token is stored only on this device (never in the public store files). Create it on GitHub → Settings → Developer settings → Fine-grained tokens (repo ink-and-blink, Contents: Read and write).

🔑 Dashboard Password

The password is saved to your GitHub repo, so it works on every device and is never lost when browser data is cleared.
Requires your GitHub token (set it once in the ☁️ Publish tab).
